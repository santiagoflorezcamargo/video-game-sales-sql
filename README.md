# video-game-sales-sql
# 🎮 Video Game Sales Analysis with SQL / Análisis de Ventas de Videojuegos con SQL

## 📍 English

This project is a complete SQL analysis of global video game sales. It includes data cleaning, descriptive statistics, regional breakdowns, and yearly trends.  
The dataset includes information by platform, genre, publisher, and release year.

📂 **Included files**:
- `Video Game Sales Analysis EN.sql`: All SQL queries used for data cleaning, analysis, and insights.
- `Video Game Sales Report (In English).pdf`: Visual report with screenshots of query results and written analysis.

🔍 **Key insights**:
- Best-selling platforms, genres, and publishers globally.
- Regional preferences (North America, Europe, Japan, Others).
- Yearly trends and rankings.
- Measures of dispersion and variability (standard deviation, coefficients of variation, etc.).

🧠 **Tools**: MySQL

👤 **Author**: Santiago Flórez

## 📍 Español

Este proyecto es un análisis completo en SQL de las ventas globales de videojuegos. Incluye limpieza de datos, estadísticas descriptivas, desglose regional y tendencias anuales.  
El conjunto de datos contiene información por plataforma, género, publicador y año de lanzamiento.

📂 **Archivos incluidos**:
- `Video Game Sales Analysis EN.sql`: Consultas SQL utilizadas para limpieza, análisis y hallazgos.
- `Video Game Sales Report (En Español).pdf`: Informe visual con capturas de resultados y análisis escrito.

🔍 **Hallazgos principales**:
- Plataformas, géneros y publicadores con mayores ventas a nivel global.
- Preferencias por región (Norteamérica, Europa, Japón, Otras).
- Rankings y tendencias anuales.
- Medidas de dispersión y variabilidad (desviación estándar, coeficiente de variación, etc.).

🧠 **Herramientas**: MySQL

👤 **Autor**: Santiago Flórez
